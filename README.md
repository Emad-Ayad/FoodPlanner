## MAD46_Food Planner – Android Meal Planner 

### Features
- Browse meals by categories.
- Search meals by name or ingredient.
- View detailed information about each meal.
- Add meals to favorites.
- Meal planner to schedule meals for different days.
- User authentication with guest and logged-in modes.
- Clean UI and intuitive navigation.

### Screens
1. **Home Screen:** Displays popular meals and navigation to other sections.
2. **Categories Screen:** Shows meal categories.
3. **Meals by Category:** Lists meals filtered by category.
4. **Search Screen:** Search meals by keyword.
5. **Details Screen:** Shows detailed info for selected meals.
6. **Favorites Screen:** Manage favorite meals.
7. **Planner Screen:** Schedule meals.
8. **Profile Screen:** View user info, log out, or log in.
